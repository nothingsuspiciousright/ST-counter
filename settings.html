Независима от Summarize, векторов и лорбуков. Исходная история сохраняется; в контекст передаются выбранные записи.

Готово к настройке.

Используй отдельный Connection Profile (например, Flash-Lite). Основная модель отыгрыша не переключается, API-ключ в Mnemosyne не вводится.

Маленькая серебряная плашка на 3 секунды. Без звука и вибрации; только после сохранения обработанной памяти, не после каждого сообщения.

Память работает незаметно: факты поддерживают непрерывность сюжета, но сами по себе не вызывают флешбеки. Старые сцены извлекаются при конкретной связи с текущим постом или явном воспоминании.

Полочки памяти

Тематические полочки содержат отдельные факты архивариуса. Полочка «Полные recap» показывает текст каждого сохранённого recap целиком, непосредственно из оригинального сообщения, без нового пересказа или оплаты API. Оригинал старой книги находится во вкладке «Наследие».

Наследие памяти · Memory Inheritance

Одноразовый перенос старой Memory Book. Книга и оригиналы остаются нетронутыми. Одинаковый импорт распознаётся без дублирования. Summarize выключай вручную только после проверки.

Первичный перенос сортирует фрагменты без API-запросов и сохраняет оригинал. Для более точной раскладки можно запустить отдельную модель архивариуса.

Переразметка повторно оплачивает API-запросы. Обрабатывает книгу мелкими частями, сохраняет прогресс и заменяет старые классификации только после полного завершения. Перед запуском скачай полный архив.
